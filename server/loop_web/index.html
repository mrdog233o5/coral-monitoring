Closed-Loop Reef Health Monitoring

The top half of the block diagram (Measurement → LightGBM → predicted CWCHI) runs live on simulated sensors. The bottom half is the new part: instead of a Kalman filter, this version does a hard write — when you press the button, the loop state is set directly to the diver's measured CoralWatch health index. Between presses the loop keeps running on its own predictions, so the correction is manual and never automatic.

Simulation notes

v1 · hard write
  • Ground truth is simulated. The dashed coral line is the reef the probes are actually sampling. In a real deployment you would not see it; it is shown here so you can watch the prediction drift and snap back.
  • Loop state = CoralWatch health index. Only CWCHI is carried between ticks. The five probe parameters are measured fresh every tick and are not part of the corrected state.
  • Hard write, not Kalman. Each button press writes the diver's measured CWCHI into the state once. Nothing is corrected automatically; replacing this with a real Kalman filter is the next version.

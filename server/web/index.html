This demo uses an extended 0–6 coral colour-chart index (0 = fully bleached / dead, 6 = very healthy); the average over a whole transect is a decimal. The index has inertia: it only moves a limited step per day and recovery is slower than decline, so the prediction usually stays close to yesterday's value. The model takes yesterday's four sensor averages (temperature, pH, nitrate, PAR) plus that day's health index and predicts today's health index; the sensors mainly nudge the direction and size of the daily change.
Demo model: trained on synthetic data, for exploration and demonstration only — not a scientific conclusion about real reefs.
